# hEvo benchmark

The benchmark component evaluates configured models and renders figures from
S-series CSV inputs. The annotated R-series tables are
the reader-facing release for inspecting and reusing numerical results.

## Choose an entry point

| Purpose | Guide |
|---|---|
| Read annotated results and column definitions | [R01–R28 tables](tables/repository_tables/README.md) |
| Reproduce figure source tables | [S-series inputs](tables/README.md) |
| Select a model or task and set runtime paths | [Configuration guide](configs/README.md) |
| Run evaluation and preprocessing tools | [Workflow index](scripts/README.md) |
| Render publication and companion figures | [Figure guide](figures/README.md) |

Run commands in the working directory specified by each workflow guide.
Runtime inputs and output locations are configured through YAML or explicit
command-line arguments. Source data dictionaries and figure input files are
linked from the table guides.
